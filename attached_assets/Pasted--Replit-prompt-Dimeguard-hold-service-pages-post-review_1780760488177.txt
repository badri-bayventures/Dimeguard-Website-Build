### 2. Calculator fine-print — make it accurate (compliance-sensitive)

In `src/components/calc-teaser.tsx`, the small disclaimer line at the bottom currently reads:

```
Estimate · {prePct}% pre / {postPct}% in-retirement · {drawdownYears}-yr drawdown · stress-tested both ways. Not advice — for informational purposes only.
```

Two problems: (a) it shows `{drawdownYears}` (the config default, 25) instead of the user-adjusted `drawdownYearsValue`, so when a visitor changes "Years in retirement" the headline updates but this line doesn't; (b) it claims a `{postPct}%` "in-retirement" return that the calculator does NOT actually model (`project()` never uses `assumedAnnualReturnPost`), and "stress-tested both ways" implies a two-scenario model that doesn't exist.

Fix the line to describe only what the model actually does, using the live adjusted values:

```
Estimate · {prePct}% annual return · {drawdownYearsValue}-yr retirement · Not advice — for informational purposes only.
```

Do not introduce any new assumption. `assumedAnnualReturnPost` stays unused.
